# Admin interface — controls (E4b.1 UX 18)

One set of controls for the whole interface. Screenshot: `controls.png` (the "Domenii permise" area:
header, status bar, list rows, secondary and quiet buttons).

| Control          | Class / element                                                                               | When                                                                                                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Primary button   | `.button.button--primary`                                                                     | The page's one main action: "Publică", the confirmation in a dialog, "Continuă spre autentificare". Never more than one on screen (unit test).                                        |
| Secondary button | `.button`                                                                                     | Every other action: "Încarcă imagine", "Copiază", "Adaugă domeniu", "Renunță la modificări", "Verifică instalarea".                                                                   |
| Quiet button     | `.button.button--quiet`                                                                       | Row actions next to a field: "Elimină".                                                                                                                                               |
| Danger button    | `.button.button--danger`                                                                      | Destructive confirmations in dialogs ("Renunță la modificări").                                                                                                                       |
| Text action      | `.link-button` (a `<button>`)                                                                 | Small actions in a line of text: "Altă organizație?", "Fixează valoarea", "Revino la automat". Underlined, but it does not navigate.                                                  |
| Link             | `<a>`, underlined in text                                                                     | Navigation only: "Domenii permise" from the checklist, the error badge (to the field). The sidebar's areas are a navigation list (not underlined; `aria-current` on the current one). |
| On/off setting   | `SwitchRow` (`role="switch"`)                                                                 | Every on/off setting; the settings of a feature open under its row. No checkboxes (unit test).                                                                                        |
| Visual choice    | radio tiles (`OptionGrid`)                                                                    | Icons and avatars.                                                                                                                                                                    |
| Field error      | `.field__errors` under the field, linked with `aria-describedby`, `aria-invalid` on the field | Validation while editing; not an alert (it would interrupt typing).                                                                                                                   |
| Page error       | `.notice.notice--error` with `role="alert"`                                                   | An action that failed: loading, saving, uploading, signing in.                                                                                                                        |
| Confirmation     | polite status (`role="status"`)                                                               | Saved, published, copied.                                                                                                                                                             |

All buttons: at least 36 px high (44 px on touch screens), 8 px radius, the same 3 px focus ring.
